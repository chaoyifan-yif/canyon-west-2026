# 从内容展示页到随身旅行手册

## 旧版问题

1. 多轮 CSS 追加覆盖：日程卡被加上深色背景，却继续继承深色文字。
2. 六个导航入口把地图、住宿与当日任务拆散；使用者要先理解功能分类才能找到下一步。
3. 大横幅、重复简介和独立侧栏挤占手机首屏，候选与正文没有分清层次。
4. 演示性语言多于明确地点；真正有价值的路线、时间和导航反而靠后。
5. 已有个人数据功能缺少完整备份导入，也存在异步同步刷新打断表单的问题。

## 新结构

- 旅程：小幅峡谷插画作为封面，随后立即进入道路图与日期选择。保留道路几何、点选路段、缩放以及 A/B 折返分支，不以装饰线条代替路线。
- 当天：日期 → 地点与时间概况 → 下一项安排 / 今晚住宿 → 需要留意的事 → 时间轴。餐厅选择、拍星攻略和现场步骤折叠，不删除真实信息。
- 记录：旅途中实际发生的事。已选餐厅可回到对应餐卡编辑，餐费只生成一条对应账目。
- 行囊：低频但重要的内容集中收纳，支持住宿、私密地址和同步设置的深链接。

不添加与旅途无关的装饰型功能、打卡排行榜、虚假的实时状态或强制登录。公共内容离线可读，个人记录默认本机，云端同步自愿启用。

## 视觉与交互约束

- 单一 CSS 主题，不继续叠加旧配色补丁。
- 暖白底 + 深墨正文；砂岩红只用于强调与动作。深色拍星卡显式设定白色标题、浅色正文。
- 插画、导航图标为本地 SVG，字体使用系统字体；正文绝不压在风景图上。
- 手机四项固定导航；日期六格一行，不必水平滑动找最后一天。
- 地图手机拖动有明确开关，避免阻碍页面上下滚动。
- 保留键盘焦点、原生 details、表单标签、已选按钮 aria-pressed，以及减少动态效果的偏好。
- 使用原有个人数据 schema；不迁移、不重置数据库，不公开地址或登录凭证。
